MeshKit SDK

App-to-App MCP,
네 줄로 안전하게.

서명된 요청을 보내고, 대상 앱 경계 안에서 실행하고, 서명된 영수증으로 완료를 증명합니다. iOS Swift Package 기준 예시입니다.

Step 1 · Discovery

호출 가능한 능력을 찾는다

Open Calling Graph(OCG)에서 대상 앱이 공개한 capability를 조회합니다. 각 capability는 위험 등급(risk)과 동의 정책(consent)을 함께 선언합니다.

User / agent intent → Caller app → OCG discovery → Signed A2A request → Target validate + consent → Signed receipt
Discovery.swift
import MeshKit

// 1. 신뢰된 OCG 레지스트리에서 대상 능력을 찾는다
let graph = OpenCapabilityGraph.mintNotesSample

guard let capability = graph.findCapability("notes.append_note") else {
    throw DiscoveryError.capabilityNotFound
}

print(capability.displayName)  // "Append Note"
print(capability.risk)         // "write:user_content"
print(capability.consent)      // "per_invocation"
Step 2 · Caller

요청을 만들고 서명한다

payload는 nonce에 바인딩되어 SHA-256으로 해시되고, 요청 봉투 전체가 caller 키로 서명됩니다. 그런 다음 URL scheme으로 인코딩해 대상 앱으로 전달합니다.

CallerFlow.swift
// 2-1. 호출자 신원과 대상 능력
let caller = MeshIdentity(
    appId: "app.hermeschat",
    installId: "install-7f3a",
    bundleId: "works.zep.HermesChat",
    publicKeyId: "hermes-ed25519-2026"
)

let target = MeshCapability(
    targetBundleId: "works.zep.MintNotes",
    capabilityId: "notes.append_note",
    version: "1.0.0"
)

// 2-2. payload는 nonce에 바인딩되어 해시된다 (replay 방지)
let payload = ["title": "회의 메모", "body": "MeshKit 데모 결정사항"]
let nonce = UUID().uuidString
let payloadHash = MeshRequestPayloadHasher.hash(for: payload, nonce: nonce)

let request = MeshRequest(
    requestId: UUID().uuidString,
    caller: caller,
    target: target,
    payload: payload,
    payloadHash: payloadHash,
    nonce: nonce,
    timestamp: ISO8601DateFormatter().string(from: .now),
    signature: .unsigned   // 서명 직전 placeholder
)

// 2-3. caller 키로 요청 봉투 전체를 서명
let signed = try MeshSignedRequestCrypto.sign(request, signer: hermesSigner)

// 2-4. URL scheme으로 인코딩해 대상 앱 열기
let encoded = try signed.encodedForURLScheme()
let url = URL(string: "mintnotes://mesh?request=\(encoded)")!
UIApplication.shared.open(url)
Step 3 · Target

대상 앱이 검증하고 실행한다

대상 앱은 자신의 경계 안에서 fail-closed로 검증합니다. 단 하나라도 어긋나면 실행은 일어나지 않습니다. validatePublicMesh가 모든 게이트를 한 번에 통과시킵니다.

TargetHandler.swift
// 3-1. 대상이 받아들이는 정책 — 누가, 무엇을 부를 수 있나
let policy = MeshTargetPolicy(
    allowedCallerAppId: "app.hermeschat",
    targetBundleId: "works.zep.MintNotes",
    capabilityId: "notes.append_note"
)

let trust = MeshSenderTrust(
    callerAppId: "app.hermeschat",
    callerBundleId: "works.zep.HermesChat",
    teamId: "ABCDE12345",
    requestSigningAlgorithm: "ed25519",
    requestSigningKeyId: "hermes-ed25519-2026",
    publicKey: hermesPublicKeyBase64
)

let invocation = MeshInvocationPolicy(
    risk: "write:user_content",
    consent: "per_invocation",
    userApproved: true,            // 사용자가 동의 게이트를 눌렀다
    registrySignatureVerified: true
)

// 3-2. 모든 fail-closed 게이트를 한 번에 통과시킨다
let audit = try MeshTarget.validatePublicMesh(
    request: incoming,
    policy: policy,
    trust: trust,
    invocationPolicy: invocation,
    observedCallerBundleId: openingApp.bundleId,
    replayCache: replayCache
)

// 3-3. 검증을 통과한 뒤에만 핸들러가 실행된다
let result = notesStore.append(
    title: incoming.payload["title"] ?? "",
    body: incoming.payload["body"] ?? ""
)

Step 4 · Proof

서명된 영수증으로 완료를 증명한다

대상 앱은 실행 결과를 대상 키로 서명한 영수증으로 돌려줍니다. 호출자는 영수증이 원래 요청과 상관관계가 맞고 대상 서명이 유효할 때만 완료를 받아들입니다.

Receipt.swift
// 4-1. 대상이 결과를 서명한 영수증으로 반환
let receipt = MeshReceipt(
    receiptId: UUID().uuidString,
    requestId: incoming.requestId,        // 원 요청과 상관관계
    capabilityId: "notes.append_note",
    targetAppId: "app.mintnotes",
    targetBundleId: "works.zep.MintNotes",
    requestPayloadHash: incoming.payloadHash,
    status: "completed",
    result: ["noteId": result.id],
    nonce: incoming.nonce,
    timestamp: ISO8601DateFormatter().string(from: .now),
    signature: try mintSigner.sign(receipt)
)

// 4-2. 호출자 측: 대상 서명이 유효할 때만 완료 수락
try MeshReceipt.verify(receipt, trust: mintReceiptTrust, against: signed)
// ✓ 통과 → 비로소 "완료"로 처리한다
